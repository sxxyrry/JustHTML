# JustHTML 工具箱

一个基于HTML、CSS和JavaScript的多功能工具箱，包含各种实用工具，无需服务器即可运行。（特殊的除外）

## 功能说明

JustHTML 是一个完全基于前端技术的多功能工具箱，集合了大量实用工具，适用于开发者和普通用户。所有工具都在浏览器中运行，无需服务器支持，保障用户隐私安全。

## 特性
- 基于前端技术（HTML、CSS、JS），无需服务端支持（特殊的除外）
- 暗色主题设计，保护眼睛
- 响应式布局，适配不同设备
- 内置关键词搜索功能，便于快速定位所需工具

## 使用方法
直接打开 [index.html](./index.html) 文件 / 打开 [官网](https://sxxyrry.github.io/JustHTML/) 即可使用所有工具。主页提供关键词搜索功能，可以快速找到所需的工具。
