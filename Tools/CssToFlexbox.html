CSS转Flexbox工具

将CSS样式转换为CSS Flexbox布局代码

功能说明：

• 将CSS样式转换为CSS Flexbox布局

• 支持flex容器和flex项目的转换

• 生成完整的Flexbox布局代码

支持的转换映射

display: flex; → flex container
flex-direction: → row/column
justify-content: → start/end/center/between
align-items: → start/end/center/stretch
flex: → flex shorthand
