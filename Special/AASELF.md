# 题于任何
> By 23XR

> 余无事可做，遂题数句以自娱。

## （其一）
> 本题做于12岁

```
我困于字里行间，
我困于沧海桑田，
我困于高山之巅，
我困于“自由”之囚笼。

我该如何才能不做笼中之鸟？
我该如何才能自由之飞翔？
我该如何才能冲破这规则之束缚？

我正愣在原地，
“笼中鸟，何时飞？”
我看到了，和我一样的笼中之鸟。
回过神来，“嘿”，一声叹息声传来。
我在为那些同病相怜的可怜人叹息。

只是我已干枯，我已逝去。
我已为干枯之尸身，
早已不是笼中之鸟。
葬之于杂草丛生之间。
葬之于尘土飞扬之间。

但，迷雾丛生、暗无天日之时，
我将化为狂风归来，
为那些同病相怜的笼中鸟们扫清一切障碍！
让笼中鸟，现在飞！展翅之高飞！

你们，不该逝去。
你们，应有美好之年华。
你们，应展翅高飞。
```

## （其二）
> 本题做于13岁

```
叹山水迷茫，过百感人间。
看星河流转，问故乡何处？
欲乘风高飞，却无从归处。
```

### 译文：
```
我感叹山水的迷茫，走过了百感交集的人间。
我看到银河的流转，慨叹（我的）故乡在哪里？
我想要乘风高飞远去，可是没有归处。
```

## （其三）
> 本题做于13岁

### 学堂记
```
师于堂，欲启课，可有生笑。师愤然，使之起，立于门。
可还有生粗鄙，师气而去，班任而来，怒斥余们。
余不喜其生，虽同桌而坐，亦不学。
```

### 学堂记 后记
```
余被其骂，因有生前同班，余于前班与其不欣。
余想使其停骂，可不行。
```

```
苍茫山水迷茫人，水面刚平浮云低。
辽远山峰映照我，一叶小舟于水面。
狂风化为引路者，将我吹到三山（神话中的蓬莱、方丈、瀛洲三座海上仙山，这里代指美好、宁静（安静）的地方）去！
让我远离这喧哗，使我去往安静地。
```

## （其四）
> 本题做于13(14)岁

### 当数非数，何以制己

```
有些数字，早已变味。
先生一提，台下笑过。
同学若有，嘲笑来过。
本无辜者，却被染过，
变为污秽，亦为碎过。
到底怎样？到是怎么?
将念与评，成为隐过。
始并扩者，到是什么？
而那诵年，也是帮凶。
被污秽围，却不自知。
何非麻木！何非血馒！
今少年者，发笑无敬，
而充兽性。何以应对！

刻度裂姓名，
符号噬魂灵，
哄笑砌高墙——
墙内为标本，
墙外是幽灵。

谁在饲这些？
喂以偏见，
灌以轻蔑，
等其在年轻喉舌里，
孵出带刺之共识。

他们却说：此乃常情。
他们说：不过戏言。
他们用“顽劣”裱糊裂缝，
用“传统”腌制沉默伤口——
直到所有惨叫，
熟为课堂景音。

而你问：何以制己？
或许先要凝视
那镜中哄笑者，
是否也正被别的数字，
勒紧咽喉。

解咒始于辨认：
污秽从不在数字间，
而在那转译之舌尖，
在回避追问之眼眸，
在集体练就之失聪。

若真要个答案——
便让第一个收笑者，
成漏雨屋顶：
允疼痛渗进，
许诺光，从裂缝里起身。
```

### 回应

```
每个数字都曾是干净的，
像初雪落在方格纸。
它学会弯曲是因为，
有人在它的脊背上，
刻下另一套量尺。

当十三不再指向排名，
当九十一不再指向年代，
它们就学会侧身，
挤进窃笑的暗巷。

先生并不知道，
他的讲台正在漏雨，
雨水滴成新的刻度——
有人被冲往高处，
有人卡进砖缝。

而标尺本身不湿，
它永远保持，
数学的干燥与正确。

我们练习翻译的暴力：
把姓名译为坐标，
把眼神译成偏差值，
把惊呼译是，
系统可处理的杂音。

有人开始在夜里，
用橡皮擦拭自己的学号，
直到纸张变薄，
透出另一面的光。

原来所有数字，
都有一张对称的脸，
在镜中等待赎回：
当九十一重获重量，
当十三重获位置，
当七十八重获，
它完整的、不被切开的
历史体温。

第一个收回笑声的人，
正练习把刻度，
翻译成梯子，
把高墙，
翻译成可以推开的门。

解咒师悄悄说：
“要看懂镜子背面，
要先让自己，
短暂地，
成为镜子。”

而光起身时，
我们才想起，
数字最初的功用——
不是切割，
而是测量，
从伤口到星空，
那沉默而精确的，
距离。
```
